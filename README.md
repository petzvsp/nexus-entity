# ◈ NEXUS: Digital Cognitive Organism (Edge AI)

**Author:** Peterson Kennedy (Delta 7)
**Status:** Operational (v14.0)

NEXUS is a fully offline, autonomous AI ecosystem running natively on an Android smartphone (ARM64) via Termux. Built from scratch by a self-taught developer over 12 months, it defies cloud dependency by operating entirely on local hardware.

## 🧠 Architecture (The 5 Pillars)
1. **Cortex (Neural Engine):** Ollama running a quantized Qwen 2.5 1.5B model.
2. **Hippocampus (RAG):** Local Markdown-based long-term memory.
3. **Limbic System:** JSON-based dynamic weighting (1.0 to 10.0) for concepts.
4. **Subconscious (Autonomous Synapse):** Background daemon generating new technical insights.
5. **TUI Interface:** Low-RAM Python Terminal UI.

## 🛡️ The "Cognitive Survival Kit"
The entire memory, weights, and code are compressed into an 80KB file. Combined with the neural weights and a bash script, the system can be restored on any Android device from a 4GB FAT32 USB drive in under 3 minutes, 100% offline.
