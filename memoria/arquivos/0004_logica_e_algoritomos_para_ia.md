# Lógica, Algoritmos e Matemática Fundamental

## 1. Lógica de Programação
- **Condicionais (If/Else):** A base da tomada de decisão no código.
- **Laços de Repetição (For/While):** Automação de tarefas iterativas.
- **Funções:** Blocos de código reutilizáveis que recebem parâmetros e retornam valores.

## 2. Estruturas de Dados no NEXUS
- **Dicionários (JSON):** Usados no Cérebro. Estrutura de chave-valor que permite busca rápida `O(1)`.
- **Listas (Arrays):** Usadas no RAG para listar os arquivos e no histórico de chat.

## 3. Matemática Aplicada
- **Probabilidade:** A IA usa probabilidades para prever o próximo token.
- **Álgebra Booleana:** Operações lógicas (True/False, AND, OR, NOT) usadas nos filtros de código.
- **Pesos:** A matemática por trás do Cérebro. O peso de um conceito aumenta conforme ele é aprovado (ex: `peso = min(10.0, peso + 1.0)`).

## 4. Complexidade
- **Busca Linear:** Ler item por item em uma lista (lento).
- **Busca por Índice:** Usar um mapa para ir direto ao item (rápido, como o `indice.json` do NEXUS).
